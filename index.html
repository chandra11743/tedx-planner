Set up a new plan (admin, one time)

  1. Go to script.google.com → New project. Delete the sample code and paste the contents of Code.gs from this app's GitHub folder. Save.
  2. Choose the function setup in the toolbar and click Run. Approve the permissions. Open Execution log and copy the ADMIN KEY.
  3. Deploy → New deployment → Web app. Execute as Me, who has access Anyone. Deploy and copy the Web app URL (ends in /exec).
  4. Paste both below to build your admin code. Keep it private: it has full control.
